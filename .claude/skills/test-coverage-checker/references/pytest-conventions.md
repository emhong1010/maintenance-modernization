# 이 프로젝트의 테스트 규칙

## 도구
- pytest. 실행: `.venv/bin/pytest -q`
- 테스트는 `tests/`에 있고 파일 이름은 `test_*.py`

## 준비
- `tests/conftest.py`의 `fresh_db` fixture(autouse)가 테스트마다 샘플 DB를 새로 만들고 `MAINT_DB`로 연결한다
- 데이터가 더 필요하면 테스트 안에서 `app.add_record(...)`로 추가한다

## 작성 방식
- 함수는 `import app` 후 `app.함수()`로 부른다 (legacy를 직접 부르지 않음)
- 이름: `test_<함수>_<동작>`, docstring: 한국어 한 줄로 "무엇을 고정하는지"
- 테스트 하나에 동작 하나, 기대값은 `assert 결과 == 기대값`으로 정확히 비교
- 주제별로 `# ---------- 리콜 대상 판별 ----------` 같은 구분 주석 아래에 둔다

## 특성 테스트의 원칙
- 이상해 보여도 **현재 동작**을 고정한다 (예: 반올림이 아니라 버림)
- 기존 테스트는 고치지 않고, 새 동작은 테스트를 추가해서 고정한다
