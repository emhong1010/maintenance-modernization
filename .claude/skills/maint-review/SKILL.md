# 정비 시스템 코드 리뷰

app/ 코드 변경을 리뷰한다. 리뷰만 하고 코드는 고치지 않는다.

1. 리뷰할 파일과 CLAUDE.md의 팀 규칙을 읽는다
2. 함수마다 아래를 확인한다
   - 문자열을 이어 붙이거나 f-string으로 만든 SQL (`?` 바인딩이 아님)
   - 고객 이름·전화번호를 print하거나 로그에 남김
   - 빈 `except:`로 오류를 삼킴
   - DB 연결을 닫지 않음 (`contextlib.closing` 없음)
   - 타입 힌트나 한국어 docstring이 없음
   - legacy의 같은 함수와 동작이 달라짐 (반환 형식, 정렬, 버림, 없는 값 처리)
3. 결과를 체크리스트로 쓴다: `- [ ] [심각도] 파일:줄 — 문제 — 근거 코드 한 줄 — 수정 제안`
   심각도는 높음(보안·개인정보) / 중간(안정성) / 낮음(유지보수) 순으로 정렬한다
4. 마지막 줄에 판단을 쓴다: **승인** 또는 **수정 요청**(높음이 하나라도 있으면 수정 요청)
